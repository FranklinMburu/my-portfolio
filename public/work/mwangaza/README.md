# Mwangaza Academy

Website for a day school in Karen, Nairobi. Designed and built by Franklin Mburu Kamande (https://franklins-portfolio-v1.vercel.app/).

- Plain HTML, CSS and JavaScript. No build step: open `index.html`, or deploy the folder to any static host.
- Pinned hero where the last word of the headline and the photo in the arch change as you scroll.
- Respects reduced-motion settings and works from phone to desktop.
- Forms are demos: they validate input and show what a live build would do.
