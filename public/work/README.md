# Websites by Franklin Mburu Kamande

Showcase websites across different industries, designed and built by Franklin Mburu Kamande.

- `keja/`: Keja, a Nairobi property agency
- `ember-and-salt/`: Ember & Salt, an open-fire restaurant in Westlands, Nairobi
- `nguvu/`: Nguvu, a strength studio in Kilimani, Nairobi
- `enkare/`: Enkare, a safari camp in the Maasai Mara
- `tabasamu/`: Tabasamu Dental Studio, a dental studio in Kilimani, Nairobi
- `akiba/`: Akiba, a savings app
- `mwangaza/`: Mwangaza Academy, a day school in Karen, Nairobi
- `mlima/`: Mlima Coffee Roasters, a Kenyan coffee roaster with an online shop
- `mwamba/`: Mwamba Advocates, a law firm in Upper Hill, Nairobi

Each folder is a self-contained static site (HTML, CSS, JavaScript, self-hosted fonts and images).
Open `index.html` directly, or deploy any folder to a static host such as Vercel or Netlify.
