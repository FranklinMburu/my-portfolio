# Concept websites

Three concept websites for fictional Nairobi businesses, designed and built by Franklin Mburu Kamande:

- `ember-and-salt/` — open-fire restaurant
- `keja/` — property agency
- `nguvu/` — strength studio

Each is a self-contained static site (HTML, CSS, JavaScript, self-hosted fonts and images). Open `index.html` directly, or deploy any folder to a static host such as Vercel or Netlify.
