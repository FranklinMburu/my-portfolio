# Mlima Coffee Roasters

Website for a Kenyan coffee roaster with an online shop. Designed and built by Franklin Mburu Kamande (https://franklins-portfolio-v1.vercel.app/).

- Plain HTML, CSS and JavaScript. No build step: open `index.html`, or deploy the folder to any static host.
- Scroll-driven hero: the photo closes into a single cherry. Working cart with sizes, grinds and a subscription picker.
- Respects reduced-motion settings and works from phone to desktop.
- Forms are demos: they validate input and show what a live build would do.
