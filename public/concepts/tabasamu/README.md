# Tabasamu Dental Studio

Website for a dental studio in Kilimani, Nairobi. Designed and built by Franklin Mburu Kamande (https://franklins-portfolio-v1.vercel.app/).

- Plain HTML, CSS and JavaScript. No build step: open `index.html`, or deploy the folder to any static host.
- Scroll-driven hero: a smile-shaped window opens to full screen. Booking widget with treatment, day and time slots.
- Respects reduced-motion settings and works from phone to desktop.
- Forms are demos: they validate input and show what a live build would do.
