# Keja — concept website

A concept website for a fictional Nairobi property agency. Designed and built by Franklin Mburu Kamande.
The agency, homes and prices are fictional.

- Plain HTML, CSS and JavaScript. No build step: open `index.html`, or deploy the folder to any static host.
- Scroll-driven hero: a `--p` (0–1) progress variable lets a home rise through the KEJA letters and open to full screen. Respects `prefers-reduced-motion`.
- Forms are demos and say so; nothing is sent anywhere.
