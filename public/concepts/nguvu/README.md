# Nguvu — concept website

A concept website for a fictional strength studio in Kilimani, Nairobi. Designed and built by Franklin Mburu Kamande.
The studio, timetable and prices are fictional.

- Plain HTML, CSS and JavaScript. No build step: open `index.html`, or deploy the folder to any static host.
- The classes strip is pinned and slides sideways as you scroll on larger screens; on phones and with reduced motion it becomes a normal vertical list.
- The booking form is a demo and says so; nothing is sent anywhere.
